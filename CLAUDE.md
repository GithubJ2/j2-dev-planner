# ProjectR: rules for anyone (or any Claude) working here

- People outside J2 (suppliers, vendors, partners, clients) are never named in ProjectR or Supabase.
  Use the **External** chip (usually "waiting on") and name the company instead, e.g. "Jobix (External)".
- Only J2 staff appear by name in owner / waiting-on chips, task titles, notes and comments.
- Every main task's steps live in subtasks, each with its own owner / waiting-on, due date and order. No long description boxes.
